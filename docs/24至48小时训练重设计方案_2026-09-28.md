# 24–48 小时训练重设计方案

> 历史研究稿：用户随后明确 24–48h 仅为心理预期。本文件中的阶段硬配额、固定三成员及按配额限制更新的建议已撤回，不作为执行配置。当前无配额优化实现与使用方式见 [训练优化实现与使用](训练优化实现与使用_2026-09-28.md)。以下原稿保留用于溯源。

日期：2026-09-28。状态：研究方案，尚未替换正式训练实现或配置。

## 1. 决策与约束

目标改为：在现有 RTX 3080 10GB、32GB 系统内存上，以约 24 小时为目标、48 小时为上限，完成一轮有明确范围的响应预测、状态识别、辅助校正及 DA-AC/DLPA 对照。表达预测和方案选择同等重要。时间约束属于实验调度，不加入药物、剂量、时长、步数或风险奖励惩罚。

推荐路线：**无损数据重排 + 全基因紧凑条件流 + 快速主训练/完整端点微调 + 单步决策评分复用 + 分阶段更新预算**。潜空间条件流和直接条件运输映射作为有定额的小规模候选，不同时从头跑完所有大模型。

不能继续将所有模块统一设置为 1000 epoch。当前整套旧协议没有被证明可在 48 小时完成；本方案中的时间表是资源配额，必须经随机条件和完整评分链的短测准入。达到时间上限而未完成的任务记录为 `budget_exhausted`，不能标记成功。

本轮只增加分析脚本、短测结果和本文，没有修改 `src/`、`configs/`、`train.py`、数据或正式模型权重；诊断执行了前后向但没有 optimizer 更新。

## 3. 先修数据路径，保持科学语义

### 3.1 建议的数据布局

保留原始分片作为来源；额外构建有版本的条件索引和未压缩 CSR/memmap 缓存。缓存稀疏原始计数及行索引，不把全体细胞展开成巨大的稠密标准化矩阵。训练时按选定行读取，再作与现行方案一致的归一化和全基因映射。

把当前的“抽一批细胞→分散打开几十个压缩包”改为“抽相同细胞 ID→索引直达计数行→批量传输”。对照池使用数组索引，减少逐细胞 DataFrame 构造；有界预取和 pinned memory 与 GPU 计算重叠。缓存设实际内存字节上限，不能占满仅有的 32GB RAM。

### 3.2 必须保持的约束

- 同一 RNG 状态下，细胞 ID、行顺序、重复采样次数、数值和对照匹配一致。物理读取可以去重，但返回结果必须恢复所有重复及顺序。
- 原始分片 hash、角色、基因顺序、归一化版本进入缓存身份；所有拟合统计仍只用相应允许的训练部分。
- T/V/R/G/C/E 的访问边界保留，不能通过一个全局缓存绕过读取权限。
- 首次转换、写盘、校验和跨条件冷读也计入本次 24/48h 预算。当前尚未实现全量缓存，因此没有证据可把热输入时间直接外推到全库。

## 4. 响应模型与训练目标

### 4.1 主方案：保留全基因紧凑条件流，重设计训练日程

继续以全基因表达 x、药物结构、剂量、真实处理时间及背景作为输入；生成状态仍为全部 32,461 个基因。先保留现有 compact 骨干作为可复用实现，避免在未确定瓶颈时再次重写全部网络。

CFM 主训练可从中间状态直接学习速度，不需要逐次展开完整 ODE。设 y 为药后训练表达、ε 为标准高斯噪声、τ 为生成时间、σ 为现有端点平滑参数，定义：

$$
x_\tau=[1-(1-\sigma)\tau]\epsilon+\tau y,\quad
u=y-(1-\sigma)\epsilon,\quad
L_{\rm CFM}=\mathbb E\|v_\theta(x_\tau,\tau\mid x,c)-u\|^2.
$$

此路径对应 Flow Matching 原文的线性高斯路径；CFM/FM 梯度等价需要原文所列密度等条件，并不保证有限网络的精度或任意离散积分的准确性。[Lipman 等，v2，§3.2 Theorem 2、§4.1 Eq.23](https://arxiv.org/html/2210.02747v2#S3.SS2)

重新核对 Zotero 内 scDFM 的英文正文（item key `IV3FSCKB`，parent 1642、PDF context 1644）以及 arXiv v1 后，确认 §3.2 和附录 Algorithm 2 使用一步端点辅助 MMD；完整多步积分属于推理。其基因子集实验也不能直接证明本项目全基因 PAD 的计算可行性。[scDFM v1，§3.2 和附录 A.3](https://arxiv.org/html/2602.07103v1#S3.SS2)

据此提出本课题的候选日程：

1. 快速阶段：CFM，或 CFM＋一步端点辅助 MMD。
2. 精修阶段：保留 CFM，增加真实完整生成端点的 MMD；使用已测可容纳的直接计算图，避免两遍重放与重算。
3. 选择及发布：基于独立 V 条件、真正从噪声生成的分布指标，不用一步辅助损失冒充推理精度。

一步近似为 \(\hat y_1=x_\tau+(1-\tau)v_\theta\)。按本项目的 σ 路径，当速度等于条件目标时，端点为 \(y+\sigma\epsilon\)，辅助比较分布需要与此对应。中间状态包含训练目标 y，因此该近似仅作训练辅助，不能把其预测误差当作自由生成质量。

此两阶段日程是新实验协议，**不与旧的全程完整端点联合训练等价**。示例一步权重 0.1 仅用于性能测量，尚不是经精度筛选的最优值。应以固定短预算比较 CFM-only、一步辅助、完整端点精修的增量。

若希望首先保持原损失，则先采用“无损读取＋完整图直接反传”的保守路线。它仍可作为同目标基线，不应与方法变化混在一起报告加速。

### 4.2 结构候选 B：潜空间流＋一次全基因解码

本课题候选结构：全基因 E 编码至 d=256/512 的候选空间，流模型只处理潜变量，最后 D 解码一次到全基因。相比当前每个 ODE 步都跨完整基因轴投影，计算复杂度由重复的 G×d 运算转向潜空间运算。

基本输出为 D(z_hat)。另一个明确独立的残差候选为 \(x+D(\hat z)-D(E(x))\)，用于保留输入中的部分细节；它不能证明无损，也可能把技术噪声保留下来。必须检查全基因、低表达、差异表达、凋亡相关基因和群体异质性的重构及响应误差。

E/D 只能使用该实验允许的训练数据；不得使用被排除的时间点目标来预训练所有 fold 的共享编码器。低重构误差也不能替代扰动预测或候选排序验证。

### 4.3 结构候选 C：直接条件运输映射

可比较一次条件映射 \(\hat y=D(T(E(x),c))\)，省去 ODE。CMonge 的原始预印本及作者代码提供了相关先例：冻结自编码器后学习条件运输，目标为 Sinkhorn 分布拟合加 Monge Gap。原论文使用 1000 HVG 和 50 维潜空间，不证明本项目全基因版本有效。固定输入的确定性映射也不自动产生单细胞随机结局。[原始版本 §2.1–2.3](https://arxiv.org/html/2504.08328v1#S2.SS1)、[官方映射与解码调用](https://github.com/AI4SCR/conditional-monge-gap/blob/195f5cd1822e7c7de7c7ee842a7e4082992ccc04/cmonge/trainers/conditional_monge_trainer.py#L260-L287)

该方法有 2026 年正式发表记录，但本轮技术细节核查来自 2025 v1 与指定源码 SHA；没有逐项核验正式版 Methods 的差异。它是更换模型和目标的候选，不是把 MMD 改个名字。

MeanFlow 可作为后续单步生成研究方向；其平均速度目标包含 JVP 和停止梯度，不能靠把当前 ODE 步数改成 1 来实现。本次不把尚未测量的这条路线纳入 48h 必做项。[MeanFlow v1，§4.1 Eqs.6–12](https://arxiv.org/html/2505.13447v1#S4.SS1)

## 5. 用更新与覆盖预算代替统一 1000 epoch

初步可执行协议建议如下；具体上限须通过阶段校准后冻结，不能按最终 E 结果反向调整。

| 内容 | 建议 |
|---|---|
| 公平结构筛选 | 一个成员、相同更新预算、相同允许数据与随机流；只给少量候选固定的小额预算 |
| 主模型 | 胜出设置再形成 3 个独立初始化/训练随机流的成员；不能把同一 checkpoint 复制三次称为独立训练 |
| 更新上限 | 首版候选每主成员 2000–4000 次更新，不统一套 1000 epoch；其数量不是收敛保证 |
| 两阶段比例 | 先评估约 80–90% 快速更新＋10–20% 完整端点精修；属于待检验日程 |
| 覆盖 | 报告抽到的条件次数、唯一条件、细胞 ID 覆盖；644 次有放回条件抽样不是遍历全部细胞 |
| 学习率 | 按更新调度；预热按总更新的一小段设置，避免沿用 10 个重型 epoch 的预热 |
| 验证 | 固定 V 监测子集按更新间隔检查，发布前完整 V 验证；明确标记两种指标，不混线 |
| 保存 | 最佳模型及时保存；常规恢复点按约 60s 或若干完整更新保存，避免快速更新时每次写大文件 |

公平对照必须同预算、同成员数报告。较长训练或三成员集成的主模型成绩单独列出，不拿它与单成员短训练的消融直接证明架构优势。V 选择与最终 E 报告隔离；状态识别、辅助回归、策略学习各有自己的终止规则。

独立训练种子不等于预测误差独立。3 成员的分歧与实际误差之间仍需 R/G/C 或对应 OOF 校准，不能沿用旧 5 成员校准文件。

## 6. 决策训练必须同时改造

### 6.1 当前是单步条件选择

现行 Tahoe 默认协议选择一次 24h 暴露后终止；时间分支也是一次 72h 条件选择。因此当前 H=1，不能把它说成已完成真实序贯 RL。药物、剂量、时间仍作为合法联合候选。

在 H=1、终态势函数为零、初态分布不由动作决定时，当前塑形回报为

$$R'=R-\Phi(s_0).$$

对固定初态，这一动作无关的常数不改变最优动作。**本课题直接推导：可显式采用 Φ=0，省去无必要的大规模潜势拟合。** Critic 的数值尺度和训练轨迹会变，旧 replay/价值网络不能无变化续用。potential 阶段原来承担的数值与群体审计必须保留并独立登记，不能随网络拟合一起删除。

### 6.2 冻结环境后的有限模拟评分库

为访问过的 root—联合动作保存独立群体重复评分。缓存完整冻结链 P→B/K/U→状态/终点评价后的最终标量，不先平均表达再过非线性网络。

$$Q(s,a)=\mathbb E_\omega R(s,a;\omega),\qquad
\widehat Q_J(s,a)=J^{-1}\sum_{j=1}^{J}R(s,a;\omega_j).$$

DA-AC 仍实际更新 Actor/Critic；DLPA 仍执行候选抽样、elite 更新及 proposal 蒸馏。二者通过相同权限的 oracle 接口请求结果，不向 Actor 暴露完整隐藏分数表。保留枚举评分这一必要简单基线。

新库把持续产生新模拟的目标改为有限 Monte Carlo 经验目标。重复抽同一库不会增加独立模拟量；每个算法的查询量、缓存命中量和真正生成量分别记录。精确复用旧 seed 的缓存属于等价工程操作，但旧协议每轮改变 seed，命中有限；共享有限库必须登记为新协议。

键至少包含 root 细胞 ID/表达及角色、完整动作与协议、全部权重及校准 hash、预处理、生成步数、群体大小和随机流身份。T 训练库、V 选择库、独立赢家审计及 E 评测流隔离。最终审计实际调用冻结原模型的新随机样本，不能重新抽训练库代替。

采用 16/32 步及较小群体作为训练评分候选，必须在允许的开发范围内与 128 步/较大群体比较表达分布与候选排名，再决定是否采用；步数少的短测不能证明其精度通过。新人口规模也须重新拟合/校准依赖群体统计的模块。

为控制评分库规模，按真正模型调用数分配预算，可先评估合计约 25,000/50,000 次群体评分的 24h/48h 候选上限，而不是原先上千万至上十亿次的循环上限。该数是待计时的设计预算，覆盖多少 root/动作/重复必须显式登记；覆盖不足不能称为任意状态上的有效策略。

## 7. 时间分支：保留嵌套隔离，避免反复冷启动

现有外4折、内3折加最终全开发集，实际是 17 套响应集成；5 成员意味着 85 次响应拟合，此外有 B/K/U。不能因为控制台显示一个节点，就把它当作只训练一个模型。

现行协议允许各 fold 使用所有已知 24h 数据，只限制相应的 72h 目标。因此可为每个成员分别用**允许的 24h 数据**建立独立预训练起点，再在各 fold 的合法 72h 训练部分微调。每个 fold 都从自己的共享预训练起点出发，不接续前一个 fold 已见过的 72h 参数。[可见性规则](../src/lung/timecourse/data.py:122)、[嵌套身份及调用](../src/lung/timecourse/nested.py:63)

预训练的选择、超参数和坐标统计也不能利用 excluded 72h、C72h 或 E72h。结论是已知这些药物 24h 条件下的留出 72h 预测，不是完全未见药物的泛化。

采用 3 个独立起点时仍有 51 次 fold 响应微调。外4/内3不能偷偷取消。每 fold 使用提前固定的更新预算，或只在其 fit 集内部设置选择子集；不能拿待生成 OOF 残差的 held-out fold 做早停。共享表征/小型适配器可作进一步候选，但冻结表征是否损失72h响应能力需另验。

## 8. 时间配额与准入

以下为一轮新协议的设计配额，**不是已测完整 ETA**。包括首次数据转换、主链、两种决策与时间分支；旧19节点原预算不能原样保留。低优先级大规模超参数搜索、全部候选骨干的完整复现、更多细胞系和真实多步扩展不在这轮范围。

| 阶段 | 24h 目标配额 | 48h 最大配额 |
|---|---:|---:|
| 数据布局准备与随机条件吞吐校准 | 1h | 2h |
| 响应候选小试、主模型及必要公平对照 | 7h | 12h |
| 状态识别及 Tahoe 辅助校正/校准 | 2h | 4h |
| 时间分支共享预训练、合法嵌套与辅助链 | 4h | 8h |
| 评分库、DA-AC/DLPA及共同基线 | 6h | 12h |
| 冻结完整评估与发布检查 | 3h | 6h |
| 余量 | 1h | 4h |
| 合计 | 24h | 48h |

24h 表示目标，48h 表示资源上限；不能从“有配额”推导“已能全部完成”。只允许一条通过准入的主架构进入整套训练，其他架构的小试也消耗表内额度。

预算必须按实际工作单元核算：

$$T_{\rm all}=T_{\rm cache}+\sum_i(U_i t_i+V_i t_{V,i})
+T_{\rm aux}+N_{\rm oracle}t_{\rm full\ score}
+T_{\rm policy}+T_{\rm audit}+T_{\rm IO}.$$

其中时间 fold、3个响应成员、策略种子、模型群体重复分别计数。完整评分计时必须包括所有成员与 B/K/U/状态头，不能用单成员裸生成计时替代。对各阶段实测波动和保存/审计预留余量；准入预计超过48h就不得开始盲目长跑。

工程目标可以设为新主训练单成员一轮达到数分钟量级，但当前只有热输入短测，尚未达成完整数据证明。发布前至少验证：

1. 随机真实条件的冷/热读取和批次一致性；工作集超过 RAM 后也能持续供数。
2. 若使用完整图，同参数、数据、噪声与时间点下，loss、全部参数梯度及一次 optimizer 更新与重放实现相符。
3. 完整验证、完整群体评分、时间随机 fold 各自计时，不靠单一条件外推所有阶段。
4. 在合法 V 上比较全基因与变化量误差、分布指标、状态识别及排名稳定性；对化学组/实验组统计，不把细胞数量当生物重复数。
5. 策略越过 warmup 并真正发生 Actor/Critic 或 proposal 更新；两方法均有独立复评。
6. 截止调度保留保存和最终评估时间；超时或精度未达发布标准如实登记，所有必需阶段完成后才标整套完成。

最终 E 不参与任何方案、人口数、步数、停止点或架构选择。模型内代理回报提升不能被写成真实凋亡率或患者获益。
