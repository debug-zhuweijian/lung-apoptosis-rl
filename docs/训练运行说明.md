# 训练运行说明

更新：2026-09-24。正式训练由用户在 PyCharm 中启动；本轮只进行了程序测试和有明确标记的小规模工程检查。

## 1. 在 PyCharm 开始

1. 打开整个目录 `I:\科研\肺癌细胞凋亡-强化学习`，不要只打开 `src`。
2. 选择已有 Conda 解释器 `F:\anaconda\envs\study\python.exe`。
3. 直接运行最外层 [train.py](../train.py)，不需要 Script parameters。

默认配置在 [configs/train.yaml](../configs/train.yaml)：`stage: response`、`task: RESPONSE-A549-V1`、`epochs: 1000`、`device: cuda:0`。默认没有普通早停。五个响应模型分别训练 1000 个 epoch，不把它们合成一条计数。

第一次运行顺序：检查解释器和数据版本 → 构建只使用 T 的全基因归一化、相关邻域图与固定 MMD 带宽 → 开始响应模型训练。**2026-09-24 GPU优化后，统计、基因图矩阵运算/排序及带宽距离随训练设备使用CUDA；缓存校验、I/O和必要的近似并列复核仍使用CPU。**用户已完成表达缓存、统计及首个CPU图块，完整训练资产尚未完成；重新运行会核验并复用已完成部分，新增无损映射缓存用于加速后续扫描。各步骤有独立进度，准备不是模型epoch。锁文件存在时先确认旧进程结束，程序不会擅自清锁或启动第二个准备器。

当前性能配置为 `query_chunk=4096`、CFM/MMD/推演微批均为2；1000 epoch、完整基因轴、128个CFM对、32个MMD样本及32步训练ODE保持原定义。执行及数值验证见[GPU优化说明](GPU执行优化_2026-09-24.md)。本次源码和配置更新后直接点击运行，建立新run并接续准备缓存；不要沿用旧run配置覆盖这些设置。

当前真实包为 `08-datasets/LungCancer_A549_Integration/training-v1/`，其 `manifest.json` 为 `metadata_ready`；完成全部预处理后才变为 `complete`。不会降低共同基因数、随机抽样替代规定的精确图，或复制原始矩阵三份。

## 2. 训练时看到什么

- 终端：解释器、阶段、task、epoch、条件／回合进度、实际损失、学习率和显存。PyCharm 的 Run 控制台不是 TTY 也保留 tqdm。
- 浏览器：本地 TensorBoard，默认尝试 `http://127.0.0.1:6006`，端口冲突时使用后续端口。启动只绑定本机，健康的同项目服务会复用。
- 首次使用该浏览器时，在齿轮 Settings 打开 **Reload data**，刷新周期可设为 5 秒。若图纵轴没有涵盖新数据，关闭 **Ignore outliers in chart scaling** 或点图下的 **Fit domain to data**。这两个行为已在实际浏览器验收。
- TensorBoard 中 `response`、`state`、`potential`、`daac`、`dlpa` 分开；RL 同时保存原始终点回报和塑形回报，横轴区分 epoch、环境步、Critic 步、Actor 步及蒸馏步。
- 预处理新增独立 `preparation/` 进度，至少每5秒写入，阶段边界即时更新；它不混入模型epoch。进入模型训练前，`response` 没有新点属于正常状态。

PROXY 界面显示状态代理，不能读成真实凋亡率。名字包含 `SYNTHETIC` 或 `implementation-smoke` 的记录是工程测试，不参与论文性能统计。

## 3. 训练阶段与入口

同一个 `train.py` 通过 `configs/train.yaml` 的 `stage` 选择阶段。响应阶段完成后，其 `experiments/<run_id>/pipeline.json` 记录真实权重路径与依赖。在新阶段的配置里将 `pipeline` 设为该文件，之后直接运行 `train.py`。

| 阶段 | 做什么 | 必需前置 |
|---|---|---|
| response | 五成员稀疏 PAD 类响应模型，OT 先验、CFM、完整 ODE MMD | 完整训练资产 |
| pool | 公共群体摘要重建 | 已训练 response；V 数值 ODE 检查 |
| state | TIDYI 原始三分类和独立温度校准 | 已训练 response |
| backward | R 条件的参考均值重建 | response、pool |
| correction | R 残差拟合，G 按实体组决定门控 | response、pool、backward |
| uncertainty | R 五折交叉拟合 B/K，训练误差估计 | 已冻结上游；至少五个 R 实体 |
| endpoint | 有真实配对条件才训练群体 Annexin 终点 | 验证过的匹配监督 manifest；当前未具备 |
| potential | V 群体数值诊断 → C 校准 → 冻结参考价值 | response、pool、state；有则包括 B/K/U |
| daac | 三个条件 Actor、双 Critic、模型内回放 | 冻结世界、状态代理／终点、Phi、完整协议 |
| dlpa | 三个条件 Proposal、前缀规划与蒸馏 | 冻结世界、状态代理／终点、完整协议 |
| all | 按上述依赖顺序编排 | 显式选择 PROXY 或 ANNEXIN task |

例如要从头执行当前可支持的整条模型内流程，设置 `stage: all`、`task: PROXY-A549-V1`、`algorithm: both`。每个启用的神经网络阶段都是 1000 epoch，算法数值检查、校准迭代和局部规划轮数有各自单位。**不建议将尚无标签的 ANNEXIN 当作当前可用奖励；程序会拒绝它。**

当前响应数据只有单次 24 小时，默认合法动作保留真实观测的药物—剂量—24h 条件，不构造笛卡尔积。时间模块代码已经实现，但单一合法时长时概率为 1，不能据此声称学到了时间优化。默认单步协议没有合法的提前 STOP。多步仅接受另行登记的显式协议及 `history_support: model_assumption`；不能把这一假设升级为实测序贯证据。

## 4. 数据划分与文件

真实 Tahoe 索引共有 2,558,270 个细胞；377 个处理药物源标签按完整化学形式归为 374 组，结构未解析排除为 0。

| 外层 | 内部角色 | 细胞数 | 用途 |
|---|---|---:|---|
| train | fit / T | 1,252,438 | 响应拟合 |
| train | residual_fit / R | 294,215 | 辅助残差拟合 |
| val | selection / V | 274,163 | 选择与预登记数值诊断 |
| val | aux_selection / G | 256,458 | 纠偏门控与已定义的终点版本选择 |
| val | calibration / C | 222,868 | 一次性校准 |
| test | final_test / E | 258,128 | 冻结后的最终评估 |

T 有 644 个处理条件、V 有 137 个。这些计数包含各角色的对照细胞，不是独立实验重复数。标准化、基因图和 MMD 带宽只由 T 拟合。

TIDYI 默认 `1_to_8` 板诊断满足三类划分；反向 `8_to_1` 的固定内部选择集缺一类，程序明确拒绝，不换 seed 重抽。真实读取器对 C/E 有单独权限，决策起点通过 `sample_controls` 仅读取对照。

## 5. 保存、续训与测试

每个 run 保存：

```
experiments/<run_id>/resolved_config.yaml  初始配置
experiments/<run_id>/active_config.yaml    当前续训目标
experiments/<run_id>/pipeline.json         权重与依赖清单
experiments/<run_id>/metrics.csv           完整长表，保留各计数单位
experiments/<run_id>/results.csv           按 epoch 整理的宽表
experiments/<run_id>/results.png           曲线
checkpoints/<run_id>/<stage>/best.pt       可变的训练中最优候选
checkpoints/<run_id>/<stage>/last.pt       最近完整训练边界
checkpoints/<run_id>/<stage>/selected-<hash>.pt  已发布的不可变推理快照
logs/<run_id>/events/                     TensorBoard 数据
```

根 `test.py` 是独立入口，要求 `--pipeline` 或 `--weights`，没有训练／重拟合门控／校准调用。表达评估使用 E 及无偏 MMD U 统计量；决策评估固定候选后独立复评，再对赢家独立审计。模拟方案分数与真实序贯疗效分开报告。

等价终端命令（不是要求你改用终端）：

```powershell
& 'F:\anaconda\envs\study\python.exe' -X utf8 train.py --dry-run
& 'F:\anaconda\envs\study\python.exe' -X utf8 train.py --resume <run_id>
& 'F:\anaconda\envs\study\python.exe' -X utf8 test.py --pipeline experiments/<run_id>/pipeline.json
& 'F:\anaconda\envs\study\python.exe' -X utf8 test.py --pipeline experiments/<run_id>/pipeline.json --mode decision
```

`--resume` 继承最近保存的目标总 epoch，不额外加 1000。DA-AC 在完整回合边界、DLPA 在完整根／蒸馏更新边界保存，包含私有历史网络、优化器、回放／teacher、随机状态和计数。已经完成的阶段按完成计数跳过，不因 best 出现在较早 epoch 而重新校准。正式和 synthetic run 不能相互切换。改了上游预测器后旧辅助模型／奖励不能混用，需要重新训练其依赖链。

PyCharm 强制 Stop 可能直接结束进程；只能恢复最近已经原子保存的边界，不能保证保存尚未完成的工作。助手没有打开或配置 PyCharm，实际 PyCharm 点击启动留给用户验收。
