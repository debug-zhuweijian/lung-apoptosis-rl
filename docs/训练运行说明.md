# 训练运行说明

更新：2026-10-16。按“数据集 → 单步扰动最小实现 → 多步序贯扰动”逐步推进，在相应阶段再加入深度学习。当前代码清理没有实现新的序贯纠错或预测器 RL 后训练。

## 数据与阶段选择

使用已有解释器 `F:/anaconda/envs/study/python.exe`。项目目录为 `I:/科研/肺癌细胞凋亡-强化学习/`。

先按需要准备数据，入口是 [scripts/prepare_training.py](../scripts/prepare_training.py)。`--metadata-only` 只准备索引与划分；完整预处理也由该入口显式执行。训练入口不自动下载、整合数据或启动预处理。

[train.py](../train.py) 每次只运行明确选择的一个阶段。现有 PyCharm 配置中的 `train_modular_research.py` 保留为同一实现的入口。不带参数只显示帮助，不会训练整条链。例如：

```powershell
& 'F:/anaconda/envs/study/python.exe' train.py --stage ae
```

可选阶段为 `ae/cache/response/pool/state/backward/correction/endpoint/daac`；它们是现有代码能力，按当前研究任务选用，不要求全部执行。查看单个阶段需要什么上游模型：

```powershell
& 'F:/anaconda/envs/study/python.exe' train.py --stage response --dry-run
```

配置位于 [configs/modular_research.yaml](../configs/modular_research.yaml)。将前一阶段的 `pipeline.json` 填入配置的 `pipeline`，或在 `modular.artifacts` 明确填写上游模型路径。每次运行从头初始化本阶段的模型和优化器，上游模型与已完成的数据缓存可以复用。各阶段按最大轮数、早停或 Actor 日程结束，无墙钟时间上限。

响应训练的公共参数放在 [configs/response.yaml](../configs/response.yaml)。当前是单成员 latent CFM，`ot_samples` 同时决定 OT 点集和抽样配对数量，`lr` 为固定学习率；已删除不生效的 `cfm_samples`、`min_lr` 和成员进程参数。`train_ode_steps` 仅在显式启用 `research.latent.refine` 时使用，普通 CFM 不执行该 ODE 分支。

## 输出与检查

- 控制台显示进度和损失；`experiments/<run_id>/` 保存配置、`metrics.csv`、结束时生成的 `results.png` 和供下游读取的 `pipeline.json`。
- `checkpoints/<run_id>/` 保存最佳／最终模型及需要的校准模型。最佳权重保留选中轮次，完成摘要记录整次训练实际轮次与更新数。
- 不保存优化器、经验池或随机状态供恢复；无断点续训或 TensorBoard。主入口不再生成环境快照、运行清单、模块状态表或潜空间阶段快照。
- 模型在实际读取时检查数据、基因坐标、参数和上游表示是否匹配；不再由独立审计账本、证书或源码哈希决定能否加载。数据划分与训练／评价隔离继续保留。

Phi 训练、ODE／群体数值审计支路、冻结资格证书、Critic MC 探针及旧自动基线比较报告链已删除。基础终点奖励保持原定义。B/K 仍是既有单步残差机制，不能据此宣称已解决多步误差累积。

旧 timecourse 嵌套 P/B/K/U 训练、四板多 seed 决策比较及多成员响应训练编排已删除；timecourse 的数据读取、准备与协议代码保留，本轮没有改变数据划分。五份失效的 CFM／状态 pilot 配置及专属测试也已退出。共享目标计算和响应历史权重读取支持保留。

响应分派、辅助模型构造与依赖核对复用一次权重读取；终点特征的旧源码记录不再限制使用。推演未启用纠错时复用一次表达投影，启用纠错时仍检查纠正前后输出；没有改变奖励、随机流或双 Critic 算法。

独立评价使用 [test.py](../test.py)，例如：

```powershell
& 'F:/anaconda/envs/study/python.exe' test.py --pipeline experiments/<run_id>/pipeline.json
```

状态模型可加 `--mode state`，策略评价可加 `--mode decision`。测试集不参与训练、早停或选模；PROXY 状态代理与模拟奖励不等于真实凋亡率。本轮只清理实现并检查相关接口，没有运行正式训练或取得新的生物学效果结果。
