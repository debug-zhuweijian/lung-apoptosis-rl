## 数值实现的等价变换

32个MMD端点不同时保留全部ODE计算图。先用相同冻结输入和噪声生成整批端点，计算完整三项MMD对每个端点的导数，再逐样本重放相同完整ODE，按链式法则传播端点导数。该方法保留跨样本MMD项和完整32步梯度；模型dropout=0。两个独立测试将所有参数梯度与原生整图autograd比较通过，包括非零PAD门下的参考编码器梯度。

这是执行方式变化，数学目标仍为 `CFM + MMD`。没有截成单步去噪、混入真实Y生成、减少共同基因或只训练最后一层。单次扰动的小时与ODE生成时间始终分开。

## 实际验收

- 程序测试：截至2026-09-24，`study python -m pytest tests -q` 为 **73 passed，18 subtests passed**。测试涵盖已有数据读取器/下载器测试和新模型、数据、辅助、RL、引擎及独立集成回归。
- 完整合成流水线：`implementation-smoke-final-v1` 实际跑通 P → pool → C → B → K → U五折 → 数值审计工程模式 → C残差校准 → Phi → DA-AC → DLPA。所有日志和权重带synthetic身份，不算真实训练成绩。
- 独立测试入口：同一合成pipeline完成E表达和固定方案测试，报告`model_updates=0`，测试前后冻结文件SHA一致。状态权重独立测试也通过。
- 恢复：算法级在完整回合/规划根边界中断后恢复，最终参数与不中断运行逐张量一致；入口级验证最新目标epoch保留、已完成阶段不重复校准、真实run不能被smoke覆盖、原best继续训练不破坏旧发布快照。
- 真实数据：metadata全量划分成功；实际读取少量真实CSR计数。全训练资产仍为metadata_ready，不把未计算的T统计和图写成完成。
- 完整基因尺寸：RTX3080上对真实计数、合成33邻域图完成32461基因/256维/2+6层的CFM前后向及完整32步Heun反向；峰值张量显存2.596 GB，检查耗时675.23秒，无optimizer更新。证据以[GPU检查JSON](../logs/environment_checks/implementation/full_panel_runtime.json)为准。
- 可见UI：实际浏览器显示response/state/daac/dlpa分类；打开Reload data后，工程曲线横轴从4步自动更新到13和18步。首浏览器的Reload data默认关闭，需要按运行说明设置一次。已验证同logdir健康服务复用。
- 未操作PyCharm。异工作目录调用根入口的只读预检成功，不等于实际IDE验收。
