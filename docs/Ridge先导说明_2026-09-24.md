# 全基因 Ridge 先导 P1/P2

日期：2026-09-24。这里记录工程实现与小型合成验证，未启动真实拟合、V 选参或效果比较。它对应[真实数据先导协议 V1](G:/研究生科研文件/毕业论文/真实数据先导实验协议_V1_2026-09-24.md)第 3–4 节；输出是条件群体表达均值及简单分布基线所需平移量，不是逐细胞真实命运、凋亡率或序贯疗效。

## 手动入口

使用已登记的 `F:/anaconda/envs/study/python.exe`，在项目根目录执行：

```powershell

& 'F:/anaconda/envs/study/python.exe' scripts/fit_response_ridge.py --config configs/pilot_ridge.yaml --output experiments/pilot-ridge-v1
& 'F:/anaconda/envs/study/python.exe' scripts/report_response_pilot.py --output experiments/pilot-p0-p1-p2-v1 --shifts experiments/pilot-ridge-v1/v_delta.npz
```

第二、三条只供用户手动启动，本轮没有执行。报告在 `--shifts` 的文件同时含 `mean_prediction` 与 `point_valid` 时自动加入 P1；同文件 delta 继续提供 P2。入口不调用预处理，不更改 `train.yaml`、数据 manifest、划分或归一化资产；资产必须已经是 `complete`。默认 `cuda:0`，不存在 CUDA、显存不足或数值失败时直接报错，保留失败状态，不自动改 CPU、float32、基因数或细胞数。用户如需 CPU，可明确另存独立配置，把 `device` 改为 `cpu`，其余协议不变。

输出必须是 `experiments/` 下不存在的新子目录，已有目录拒绝覆盖。初始化后发生失败或中断，会留下 `status.json` 与已完成产物，不将半成品登记为 complete；重新执行使用新的实验目录。入口没有 E 选项，只能打开 `roles=(T,V), allow_test=False` 的数据器。底层按原有读取器核对冻结资产哈希，并可读取公共划分／条件元数据；不解析 E 响应或终点，不开启 E 权限。

## 输入、目标与实现

对应代码：[数据汇总与特征](../src/lung/engine/pilot_ridge_data.py)、[拟合与产物](../src/lung/engine/pilot_ridge.py)、[独立入口](../scripts/fit_response_ridge.py)。架构对应关系如下。

| 协议要求 | 实际实现 |
|---|---|
| 全共同基因 | 输入对照均值与目标均为冻结顺序的完整 32,461 维；没有 HVG、PCA 或基因筛选 |
| T 条件拟合 | 每个合格 T 处理条件一行，目标为该条件完整药后均值减匹配 T 对照完整均值；条件等权拟合 |
| 可得的初始信息 | 完整对照均值、冻结 2,048 位 Morgan 指纹、`log1p(dose_um)`、指纹与该剂量的逐位交互 |
| 已知背景 | 与主模型相同的 `source_id`、`background_id`、`protocol_id`，按冻结元数据词表做独热编码 |
| 时间与处理协议 | `log1p(duration_h)`、elapsed/horizon=0、duration/horizon=1、is_vehicle=0；固定 24 h 单次处理、空历史，不虚构其他时长或轨迹 |
| T 内缩放 | 仅使用 T 条件特征的均值和总体标准差（ddof=0）；常量列 scale=1，居中后为零，保留列轴 |
| V 的职责 | 仅选择预登记 λ；V 药后均值不进入输入构造、缩放或任何候选模型的系数拟合 |
| P2 输出 | 保存未投影、标准化坐标中的原始预测 delta，供报告对每个抽样对照细胞加 delta 后调用公共物理投影 |

Morgan 指纹直接读取冻结资产，不重新化学标准化。对数剂量采用主模型 `DoseEncoder` 的 `log1p(µM)` 约定。背景词表属于共享条件元数据，不从响应标签学习；某类别若在 T 中从未出现，其列在 T 中恒零，无法凭 V 产生已训练效应。单细胞与模型成员均不视作独立生物重复。

设 T 条件数为 n，特征数为 d，基因数为 G；X∈R^(n×d)，Y∈R^(n×G)。由 T 内缩放得到 Z，并使用以下明确的目标：

\[
\min_{B,b}\|Y-\mathbf1b^T-ZB\|_F^2+\lambda\|B\|_F^2.
\]

损失为平方和，不除以条件数或基因数；λ 对应这一尺度，截距不惩罚。L2 正则最小二乘及多输出形式可对照[scikit-learn Ridge 官方定义](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.Ridge.html)；本实现没有调用 sklearn 拟合器。

下面是本实现对上述目标的代数重写，不是生物学保证。因为 Z 已居中，对 b 求导得到 b=mean_T(Y)；令 Yc=Y−mean_T(Y)，对 B 求导得到 `(ZᵀZ+λI)B=ZᵀYc`。取

\[
A=(ZZ^T+\lambda I_n)^{-1}Y_c,\qquad B=Z^TA,
\]

代回正规方程可验证等价。实现通过 Cholesky 求解 A，保存 Z、A 与 T 均值／尺度；预测为 `Z_new Zᵀ A + mean_T(Y)`。因此求解矩阵是 n×n，不创建 32,461² 或 d² 系数矩阵。λ 全为正；无须满列秩。该数值实现由另写的 NumPy primal 正规方程及一维解析解测试核验，没有据此声称泛化或药效保证。

## 全量均值与精度

开始读取表达前保存全部 T/V 合格条件及对应同角色对照池的计划。分别流式扫描 T 的 `train.parquet` 与 V 的 `val.parquet`，按角色与所需条件过滤，仅对实际唯一细胞累加。共享对照池只扫描一次，再按实际细胞数合并为各条件对照均值；不按池等权，也不靠重复抽样近似全量均值。

表达矩阵每次只解码 `stream_batch_size` 行，默认 512；原有 CSR 读取器仅缓存有限分片。条件×基因的累计矩阵保留在选定设备，显示已处理细胞数与总数。细胞 ID 和 `(matrix_path,matrix_row)` 在 T/V 间共同查重，实际行数必须与冻结角色计数逐项相符；错误即停止，不删除重复后继续。

公共 `TrainingData.normalize` 固定返回 float32 标准化表达；本入口保留这一公共变换及其舍入结果，与主模型／V 报告使用同一坐标。**均值累加、输入均值／尺度、双精度线性代数、均值预测与数值产物使用 float64**，不是对公共标准化精度作隐式改写，也没有混合精度或遇错降精度。CUDA 使用双精度归约与求解；并行归约可能带来末位舍入差异，不能把小合成的一致性宣称为全数据逐位复现。

## V 选择与 P1/P2 区别

候选 λ 固定为 `[1e-4,1e-2,1,1e2,1e4]`。各候选均以 T 拟合：先输出 V 的 raw standardized delta，再计算

`P1 mean_prediction = full_unique_V_control_pool_mean + delta`。

这个量是标准化坐标中的原始群体均值，只检查有限性，不施加单细胞物理投影、裁剪或总量重归一化。对每个 V 条件计算它与完整 V 实测药后均值的全基因 RMSE，先对同一化学实体的条件取平均，再对实体等权平均。取最小者；完全并列按升序网格先出现者。任一条件含非有限预测，该 λ 整体不参加选择，保留原因及覆盖计数；不会静默去掉失败条件。`lambda_selection.json` 保存全部候选逐条件／逐实体分数、最终 λ 和包含 `raw_standardized_mean_no_projection` 的 criterion。P1 的“有效”仅表示均值向量有限，不宣称它符合单细胞物理约束。

P1 是上述**群体均值估计器**；MMD、方差等分布指标为 `null / not_applicable_mean_only`，不得把它复制成一群相同细胞再称为分布模型。完整 V 均值的分数同时参与选参，只是开发验证，不能作为独立最终测试。

P1 的 `control_summary_scope` 固定为 `full_unique_V_control_pool_mean`；P2 把同一个由全池信息预测的 delta 加到 V 报告实际抽中的对照细胞后逐细胞投影。P0、P3/P4 的报告生成则直接使用该次至多 512 个抽样对照。因此这些方法共享可用对照信息，但输入汇总方式不同，不能声称逐采样输入完全一致。**P1 原始群体均值不必等于 P2 逐细胞投影后的群体均值**；P2 保留分布基线的逐细胞物理约束。

本轮已撤回实现初稿中对 P1 均值点施加单细胞投影的做法。理由由当前表达变换与 Jensen 不等式得到，推导如下。令每个细胞的归一化计数为 `c_ig`，满足 `Σ_g c_ig=10000`，对数表达为 `l_ig=log1p(c_ig)`。`expm1` 的二阶导数为正，应用[Boyd 与 Vandenberghe《Convex Optimization》§3.1.8，式 (3.5)，印刷页 77–78](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=91)得到

\[
\sum_g\operatorname{expm1}(\bar l_g)
\leq \frac1n\sum_i\sum_g\operatorname{expm1}(l_{ig})=10000.
\]

只要至少一个基因在等权细胞间的对数表达不全相同，严格凸性使不等号严格成立。因此正确的 `mean(log1p counts)` 通常不满足单细胞的总量等式；强行重归一化会改变原本正确的目标，还可能改变 λ 排序。标准化是使用冻结均值／尺度的仿射变换，不改变这一“群体均值与单细胞不同”的结论；以上等式在精确算术下表述，实际坐标保留公共浮点舍入。

回归测试给出明确标为合成的反例：两个细胞归一化计数分别为 `[9000,1000]`、`[1000,9000]`。未投影的正确群体均值 RMSE 为 0；套用单细胞投影后 RMSE 非零。对两个实际细胞分别投影仍保持其合法表达。该反例用于验证统计目标，不能作为任何药效结论。

## 文件与报告接口

| 产物 | 内容 |
|---|---|
| `input_and_method_identity.json` | 代码、配置、协议、完整冻结训练 manifest、源审计注册表的身份与 SHA256 |
| `population_plan.json` | 全部 T/V 合格条件、组、同角色对照池、预期唯一细胞数 |
| `t_condition_means.npz` / `v_condition_means.npz` | 完整目标／对照均值、池均值和数量、基因顺序、角色、细胞读取序列摘要；不伪造逐细胞配对 |
| `lambda_selection.json` | 固定网格、未作单细胞投影的全 V 原始均值 RMSE criterion、所有候选分数和选择结果 |
| `ridge_model.npz` | T 的输入均值／尺度、居中目标均值、标准化训练设计矩阵、dual 系数、λ、特征和基因顺序、来源 metadata |
| `v_delta.npz` | P2 所需 raw delta 与 P1 点预测；详见下表 |
| `p1_full_population_metrics.json` | 每个 V 条件的全池 P1 均值 RMSE、NA 分布指标、实体等权汇总；明确选参用途 |
| `status.json` | planned / running / complete / failed；失败保留已写产物 |

所有 NPZ 仅包含数值、布尔和 Unicode 数组，禁止 object／pickle。`v_delta.npz` 字段为：

| 字段 | 语义 |
|---|---|
| `condition_ids`、`gene_ids` | 所有 V 合格处理条件及完整基因顺序 |
| `delta` | 形状 `[V条件数,G]`，有限 float64 原始标准化均值差，尚未投影 |
| `mean_prediction` | 与 delta 同行顺序的 P1 原始标准化群体均值，不作单细胞投影 |
| `point_valid` | 布尔有限性标志；非有限均值保留整行 NaN，不填 0；不表示单细胞物理有效性 |
| `metadata_json` | 标量 JSON：T/V/V 角色、输入声明、数据身份、T 拟合条件、模型／数据／源代码／选择记录／基因顺序 SHA256，以及未投影均值语义 |

该文件直接通过 `pilot.load_shifts(path, V_data)` 交给 P2；P1 使用 `pilot_ridge.load_mean_predictions(path, V_data)`，返回 `(dict[condition_id, ndarray[G]], provenance)`。后者复用 load_shifts 的角色、数据、基因与身份检查，并要求 `prediction_semantics=raw_standardized_full_control_mean_plus_delta_no_single_cell_projection`，拒绝旧投影点身份；同时检查有限性标志。未定义分布指标由统一报告保留为 NA。接口身份校验不能凭外部文件的自声明独立证明其拟合过程；本入口的拟合／选择分离仍由源码与测试核验。
