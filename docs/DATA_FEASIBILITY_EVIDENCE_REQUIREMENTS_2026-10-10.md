## Technical Review

**验收对象是“数据是否让主假设能够接受支持、反驳或不确定的检验”，不是“方法是否已经赢过基线”。**

公开图上的均值、带误差条的结果和时间曲线可以构成真实观测证据。只要来源、条件、尺度与提取误差明确，就可以用于预先冻结预测的点误差、成对顺序及不确定性敏感性检验；没有逐重复原始值会限制统计推断，但不会自动取消这些用途。

架构允许群体状态、细胞背景及来源信息作为输入。**不要求每个功能终点同时具备同细胞 t0、高维 RNA 或前后追踪。** 同时，没有这些信息时不能升级为“同一细胞的未来命运已验证”或“细粒度单细胞表达优于群体状态已验证”。

### Errors：应纠正的过强或过弱判据

- “没有原始重复就不能用图上均值做外部检验”过强。可以评价公布的均值；不能捏造重复分布或不确定性。
- “没有终点实验的初态 RNA，就不能检验任何状态条件化”过强。有来源证据、在结局之前定义的群体状态类别可以成为合法输入。
- “表达状态的信息增量必须首先在Annexin标签上证明”过强。可以在真实药后表达预测中检验；若进一步声称这一细粒度增量传递为更好的真实凋亡选择，则另需相应桥接证据。
- “必须同时满足 T/V/C/E 四分区、来源隔离和全结构解析才有科研可行性”过强。这是一种实现契约，不是全部研究任务的必要条件。
- “两状态、两药、多个时间点已经验证药物/剂量/时长的完整选择”过弱。是否同一共同终点、是否存在不同暴露时长及其后续协议，必须单独核实。
- “新数据中存在明显状态差异/排序翻转才算数据可行”不成立。零增益、同序或失败也是合法结果；不得按有利结局挑选验收数据。

### Rigor Issues：不得通过换口径消除的缺口

- 输入状态若由当前要预测的终点倒推，会造成标签泄漏。
- 不同状态只对应完全不同药物/剂量/来源时，不能在没有额外假设的情况下分离状态增量。
- 没有真实可比候选结局时，不能计算真实选择收益；模拟回报不能代替。
- 连续暴露曲线不能补造撤药后到共同终点的结果。
- 除了数据可获得，还需有可实施的输入表示、独立评价方案，以及覆盖主目标各部分的实际证据。简单接口可运行不等于完整数据可行性通过。

### Notation Issues

s：决策时可用的状态信息，可以是群体类别、背景、参考表达或其他已核实观测。  
a：完整候选，含药物、剂量、暴露时长及撤药/保留等可变协议。  
p：固定实验背景；o：观测定义。  
τ：给药后的实际观测时点；Δt：真实药物暴露时长；T*：用于比较候选的共同最终终点。三者不与生成模型内部时间混用。  
Y：实测终点；Ȳ：发表的均值；ŷ：冻结模型预测；φ：生成特征。F 表示 fold，不能直接当作 fraction。

## 1. 先区分三种验收，避免用一个布尔值概括全部

| 层级 | 通过含义 | 不包含的承诺 |
|---|---|---|
| 来源单元可用 | 某条均值、面板或曲线点有可追溯的实测依据，可以用于指定计算 | 不是独立生物重复；不是所有方法都能使用 |
| 某项检验的数据可行 | 指定输入、标签、对照、划分和指标确实可形成支持/反驳该假设的实验 | 不保证精度、显著性或改进为正；不等于其他假设已覆盖 |
| 完整主线的数据可行 | 四项主目标均有真实可用证据和可执行验证，且至少存在能够核验完整状态条件化筛选链的功能条件块 | 不等于模型已经训练成功；不等于临床或个体命运验证 |

一条数据可以“适合描述性均值挑战、暂不适合带显著性结论的泛化评估”；应保留这种分层资格，不能只用“有用/无用”两种状态。

现行 formal_training_ready 是特定消费者的工程资格。若新研究设计允许群体类别输入、均值挑战或带结构不确定性的评价，应建立明确的新协议和消费者；不能仅为了运行而删除现有守卫，也不能把旧守卫的拒绝当作数据对所有方法无效。

## 2. 科学必要条件与可调整实现

| 问题 | 科学上必要 | 不作为普遍必需条件 |
|---|---|---|
| 状态输入 | 有独立于待预测 Y 的定义和来源；说明何时可获得、代表什么粒度 | 每个 Y 都有同细胞 t0；每个状态均有高维 RNA |
| 功能标签 | 来源真实；对应明确状态、完整处理条件、检测尺度和时点 | 必须拿到 FCS 或全部逐重复值后才能计算点误差 |
| 独立评价 | 评价 Y 不参与该次拟合、选模、校准或候选挑选；划分与泛化对象一致 | 所有任务一律四固定分区；一律同时留来源、药物和所有发表图块 |
| 化学输入 | 明确研究中的哪一个化合物，避免错误跨来源连接；所选预测器有合法可复现的输入 | 每项来源内剂量研究都必须先得到唯一完整立体 SMILES |
| 测量协议 | 保留实际观测定义、缺失项和转换假设；不直接混合不等价数值 | 所有研究只能使用一种检测平台；所有检测细节必须完美齐全才能做来源内挑战 |
| 候选选择 | 决策集合、基线和最终评价事先定义；比较对象有可比真实结局 | 每个状态、每药、每剂量、每时长必须形成完整笛卡尔积 |
| 不确定性 | 已知误差和未知部分分别登记，结论不超出信息 | 必须先得到统计显著的状态优势；必须预先证明模型获胜 |

“没有高维 RNA”只阻止依赖该 RNA 的具体表示和相关主张，不自动阻止群体类别条件化。反过来，类别状态的成功不能作为高维表达增量或单细胞增量的证据。表达分布预测 P 本身仍需要相应的实测表达进行监督/验证；不要求这些表达与每个功能 Y 来自同一细胞或同一个孔。

只有来源 ID 而没有可区分的生物状态时，可以检验来源/背景条件化；若状态与来源完全重合，不能把改进唯一归因于生物状态。培养密度、状态诱导方案等与状态共同变化时，可以检验“所记录状态及背景下的预测效用”，不能据此作隔离了这些因素的因果解释。

## 3. 每条数据必须交付的最小证据记录

下表是可直接用于逐条验收的字段要求，可记录在现有表或独立 sidecar 中，不要求本轮改 schema。

| 字段组 | 必须记录 | 缺失/冲突的处理 |
|---|---|---|
| 来源 | DOI/accession、原始文件路径与 SHA256、版本、图/表/面板/坐标位置 | 只有摘要或二次数据库的关键数值，暂不标为原始证据已核实 |
| 唯一单位 | source_condition_id、observation_id；来自均值、面板还是逐重复 | 一个源数值只有一个观测身份；不得跨细胞、结构分支或图上插值点扩样 |
| 状态 | state_id、语义、证据位置、类别/群体参考/标志量/表达等类型、获得时间 | 不把药后结局定义成初态；平行时间匹配对照如实标 reference |
| 干预 | 来源限定的化合物 ID、剂量及单位、标称/相对 IC50 等依据、暴露设计 | 同编号跨文章不默认同药；剂量冲突保留多个有证据解释，不默选方便值 |
| 时间 | 暴露起止、测量时点、共同终点、撤药/换液/残留处理 | 未知不能填成持续暴露或已撤药；时间曲线不自动等于时长选择数据 |
| 观测 | 端点名称、fraction/fold/intensity 等尺度、分母、门控/图像计数规则、对照 | 早期/总阳性、流式/图像、死亡/凋亡相关信号分开 |
| 汇总 | mean/median/代表面板；生物 n 与技术 n；误差条是 SD/SEM/CI/未知 | 作者写“至少三次”不等于每点精确 n=3；未公开重复值不重构成实测值 |
| 相关性 | 同一孔随时间、多图重复、共享对照、培养批或仅知道发表图块 | 已知相关单位一起处理；未知保留，不能由文件名断言独立 |
| 数字提取 | 原表抄录/印刷数值/图像坐标提取、坐标变换、读图误差范围、复核人/日期 | 模糊点保留区间或不可判定；不伪造额外小数 |
| 输入可用性 | 预测器所需字段是否实际取得；结构/剂量解释是否唯一或有限候选集 | 特定消费者不支持不确定输入，标工程待接入，不扩大为所有研究不可行 |
| 数据暴露 | 哪些结果已用于开发、模型/特征/方向选择；拟用训练和评价角色 | 人读过公开图不自动等于算法泄漏；被用于选法的 Y 不能再称未受影响的盲测 |
| 用途资格 | 允许的任务、指标、结论粒度、未解决项 | 可多选“点误差”“顺序挑战”“训练探索”等，不只记录总布尔值 |

读图误差、源实验波动、平台转移不确定性是不同量，不能合并成一个未经解释的误差条。

## 4. 四项主目标的实际数据验收

这里给的是能够构造检验的最低信息结构，不是保证统计功效的通用样本量。每项均须填上实际 observation_id、来源位置和具体评价步骤，不能仅写“理论上将寻找”。

### A. 状态增益

**验收目标：** 在相同候选和其他允许信息下，比较状态条件化预测与状态无关/群体平均表征。首先声明预测对象：药后表达分布，或独立实测功能。二者所需的Y不同，不能将后者的标签要求套在前者上。

**A-expression：表达分布预测中的信息增量。**

1. 具有可定位的参考表达群体及相应处理条件下的实测表达。没有逐细胞前后配对时，以实际群体/条件为监督和评价单位；不宣称同一真实细胞的未来命运。
2. 全分布/单细胞集合输入与群体平均输入来自相同合法参考，处理条件、背景/来源等其他允许信息保持一致。单细胞输入可包含更丰富分布信息，但不能通过额外获知测试结果获得优势。
3. 若比较不同参考上下文下的预测，列出这些上下文、共享动作和独立单位。同期vehicle群体应标为reference；plate/来源效用不等于生物状态因果效应。同一个控制池的随机子样本不构成新的独立生物状态。
4. 划分与所声称的泛化一致，保留共享control、批次与细胞的依赖。若参考在评价时可取得，应明确该信息可用性，并让比较模型获得同一参考；不能将这种设定误称完全未见来源的归纳预测。

**A-function：功能结局上的状态条件化。**

1. 至少两个独立定义的可观测状态，在共享、可比较的处理条件下有真实功能结果，使状态不完全由动作推断。
2. 有来源证据的parental/senescent/resistant等类别可作为合法状态；无对应RNA时只能评价该类别/背景层级，不升级为表达超出类别的增量。
3. 若要把A-expression的细粒度表达增量进一步归因到功能或选择增益，须有适当的状态—功能连接，或能在所声称粒度上区分状态信息的独立外部挑战及明确转移假设。固定参考或仅类别状态的整链收益，不能仅凭转移假设归因成目标实验细粒度初态RNA的功能增量。条件参考与同样本实测配对分别登记，不把后者设为每项检验的普遍要求。

两个分支均需预先固定模型/学习程序和信息对照。已有冻结模型可以接受有限数据挑战；不要求先在同一小数据集拟合G。一个共享动作可以支持有限状态响应对比；状态条件化选择另需多个可比较动作。状态与动作、来源或其他输入完全绑定时，须限定为联合背景的预测效用，不能无假设地隔离生物状态增量。

**数据可行性通过不要求：** 两状态均值必须显著不同、加入状态必须赢、药物排序必须翻转。若状态条件化无增益，应允许得到零或负结果。

### B. 未见条件

**验收目标：** 至少有实际可保留的条件及其 Y，使“未见”有可核查定义。

- 已见药物新剂量：留出完整剂量条件及其重复，允许该药在其他剂量出现。
- 离散时间预测：留出完整观测时点/条件。若使用两侧时点，称插值/条件补全；只用此前信息预测未来，才能称相应时间外推。
- 新药：说明是 G 未见该药功能标签，还是 P/C/G 全链未见该药响应；不得混用。
- 新来源：留出研究/实验批；此时同药跨来源是可用迁移锚点，不必一律禁止。
- 同曲线留时间点回答曲线内缺点预测，不是独立新轨迹/新培养泛化；不能按点数制造独立 n。

可采用固定外部模型、明确训练/测试，或把全部选模过程放在外层留组中的嵌套设计。四个固定集合不是唯一方案。样本少时可以限定为透明的回顾性挑战，不能宣称广域可靠性。

**最低实际证据：** 明确列出训练/选择和评价各自有哪些来源单位、评价时可用哪些输入、哪些 Y 被保留、哪些指标可算。若只完成一个泛化轴，应写清该轴；不能称全部药物/剂量/时长范围已验证或均已具备数据。

### C. 真实凋亡功能一致性

**验收目标：** 预测与真实实验定义的凋亡相关结果对应，而不是与另一个模拟分数互相印证。

最低证据为一个可核实的状态—完整处理—测量时点—检测定义—真实 Y 连接。Y 可以是已公开均值或可审查图点；输入特征可以由独立冻结的 P/C 生成，不要求该 Y 配有实测药后 RNA。

Annexin fraction、Annexin fold、图像 Annexin 阳性比例可各自形成匹配的功能检验，但不能未经观测模型/桥接验证就数值合并。仅有 TIDYI 分选标签或模型代理分数不能替代该 Y。若只作排序挑战，可不先得到绝对概率校准；若报告绝对比例或阈值决策，则必须验证相应尺度。

**最低实际证据：** 已亲读源定义、数值可读取、条件可定位、生成输入具有合法语义、评价不利用该 Y 选分数方向或挑候选。跨来源同名条件可作带明示转移假设的独立挑战，但不得登记成同样本实测配对。

### D. 药物—剂量—处理时长选择

**验收目标：** 在相同状态及共同评价定义下，能比较模型实际选中的候选与真实可比备选。

最低证据：

1. 一个决策条件块内至少有两个合法候选及其可比真实终点；基线选择也应落入有结局的候选集合。
2. 研究的整体证据中，药物、剂量、真实暴露时长的变化分别可检验。不同药物可有不同合法剂量，不要求完整笛卡尔积，也不拼接未经测量的边际最优组合。
3. 涉及时长选择时，候选有同一 T*，且每个较短暴露方案从暴露结束到 T* 的撤药/换液/残留等处理及结局有实际支持。
4. 候选预筛、评分方向、模型和策略在评价 Y 前固定；报告相对已测候选的差距，不称全空间最优。
5. 单次选择以直接评分/完整候选枚举作为基线。RL 的内部高回报不是额外的真实终点数据，也不是成功的验收前提。

只有一个实测候选时，可以算点误差，不能计算该次真实排序或选择差距。若缺乏可比的固定剂量/时长基线结局，就不能补造其成绩。

### 四项如何形成完整结论

可以由不同数据集承担不同组件，但不能仅因 A、B、C、D 分别在互不兼容的任务上出现，就宣布完整链成立。至少应有一个带真实功能 Y 的状态条件化候选块，能让拟采用的完整预测—选择程序及其无状态/简单基线接受同一评价；其余资料可补充表达、剂量、时间或来源检验。

完整链可使用有来源的群体参考及明确的跨来源转移假设，不普遍要求功能实验同时测得RNA。A-expression、功能状态挑战和固定背景的联合候选块可以分工；最终仍应记录同一程序的版本、状态入口、协议编码、分数尺度和候选选择。对6h给药＋18h无药恢复等方案，必须保留完整协议；不能以连续6h、连续24h或生成内部时间τ替代。真实共同终点数据已取得而当前消费者尚不能表达协议时，应标“实现待接入”，不能改称原始数据不存在或直接宣布全链完成。

如果共同 T* 的时长结局仍缺失，则完整主线的这一项仍未通过。保持目标和缺口，不把目标改成“同一参考状态下的单药打分”来宣布完成。

## 5. 公开均值与曲线：允许怎样用

### 5.1 图上均值可以是外部真实标签

以下为**本课题分析**。设某条件的真实实验均值为 μ，发表的生物重复平均值为 Ȳ=μ+ε，E[ε]=0；预测 ŷ 在评价前冻结，并与本次实验噪声独立，则

\[
\mathbb E[(\widehat y-\bar Y)^2]
=(\widehat y-\mu)^2+\operatorname{Var}(\bar Y).
\]

这是展开平方并使用零均值交叉项得到的。它说明对发表均值的误差是合法观测量，同时含实验均值的不确定性；不能把它当作无噪声真值误差。

两个固定预测器在同一 Ȳ 上的平方误差差，其期望中的共同测量方差项会抵消。因此，没有逐重复值也可以做模型对该发表均值的配对误差比较；**不意味着已知差值的方差、已经显著，或可以将多个时间点当独立样本。**

若图表示一个代表面板而非重复均值，直接报告相对该面板的误差，不套用“n 个生物重复均值”的假设。

### 5.2 读图精度应进入误差和顺序判断

设图提取值为 ỹ，图像读取误差满足 |ỹ−Y|≤δ，则由三角不等式：

\[
\max(0,|\widehat y-\tilde y|-\delta)
\le |\widehat y-Y|
\le |\widehat y-\tilde y|+\delta.
\]

这是**读图误差范围**，不是生物学置信区间。可将固定预测误差报告为区间；图分辨率不足以支持小数点后多位时不制造精度。

对候选 i、j，如果可合理解释的结局区间满足 Lᵢ>Uⱼ，则在该不确定性范围内次序稳定；区间重叠时标为次序未确定，而不是强行判对错。SD、SEM、置信区间和人为读图容差不能互相替换；把“均值±SD”画出的范围当 95% CI 是错误用法。

### 5.3 可接受与不可接受的操作

| 操作 | 判定 |
|---|---|
| 冻结模型后对全部预登记图点计算 MAE/平方误差，并记录读图误差 | 可接受，说明评测的是报告均值/面板 |
| 同状态、同终点定义、同 T* 的候选做成对顺序挑战 | 可接受；未知次序或误差带重叠须保留 |
| 对实际观测时点计算预先规定的曲线误差或加权误差 | 可接受；不能把曲线误差改称共同 T* 的撤药选择收益 |
| 记录原文 n=3 生物重复、每次三技术重复，但只保存一个均值及 SD | 可接受；原始重复值状态仍为 unavailable |
| 把均值复制三次，命名为三个“生物重复” | 不接受 |
| 将每两个小时一个图点当作新增独立培养重复 | 不接受 |
| 用拟合曲线生成密集伪点，把这些点计为更多实测样本 | 不接受；可用于明确标注的插值，不扩充实测 n |
| 用已见待测曲线选最优模型/方向，再报同曲线的“独立验证” | 不接受 |
| n、SD/SEM 类型未知时仍计算精确 p 值或窄置信区间 | 不接受 |
| 因拿不到逐重复值，就把所有均值和顺序证据完全删除 | 不合理；应降低相应统计主张，不丢弃可核查信息 |

已公开资料可做回顾性冻结挑战。公开结果被阅读并不自动证明算法已泄漏；但必须登记哪些数值已影响选法。需要确认性结论时，保留后续未参与选法的条件或来源，不能靠重新随机划分洗去已有选择历史。

## 6. 必须单列的共同 T* 契约

以下为**本课题对架构 §4.2 的分析**。令 Cₜ 表示持续暴露直到时点 t，并在该时点评价；令 W₂₄→₄₈ 表示暴露 24 h 后撤药，再到 48 h 评价。

即使已观测 Y(C₂₄,24 h) 和 Y(C₄₈,48 h)，也没有因此观测到

\[
Y(W_{24\to48},48\text{ h}).
\]

恢复、残留药物效应、迟发死亡、群体增长等如何发生不由两个连续暴露端点唯一确定。这不是说时间曲线无用；它们能验证连续暴露下的响应随时间变化，却不能自动回答不同暴露时长在共同终点的选择问题。

**时长选择验收必须提交：** 实际暴露停止/继续时间、停止后的协议、共同 T*、每个待比候选在 T* 的真实终点。若只得到连续暴露曲线，标记“时间条件响应检验可用；共同 T* 时长选择未覆盖”，不把整个来源判废，也不把该子问题写成已解决。

## 7. 当前三个来源的具体资格

### 7.1 Navitoclax / Nav-Gal：允许进入状态×药物×时间功能挑战的核验流程

亲读 PMC7189993：§4.4（acel13142-sec-0014）写明 A549 的顺铂诱导状态；§2.3（sec-0005）、Fig. 4a/b 和 §4.6（sec-0016）描述两种状态的 Annexin 图像时程。[R1]

已核实：

- 对照与顺铂诱导 senescent A549 两种群体状态，可以作为有来源的类别输入，不需要先取得高维 RNA。
- Fig. 4b 是 Annexin V 阳性细胞的平均比例，按图像中的总细胞与阳性细胞计数；不能自动当作已有流式门控 G 的同一观测定义。
- 图注给出 n=3 生物重复，每个生物重复中每条件又有三技术重复；原图误差条为 SD。不能据此生成九条实测生物重复。
- Methods 记载每 2 h 成像；具体可提取时点和值须逐图核验，本文不代替坐标提取。
- 正文/图注给出两药各 10 μM，Methods 写两药各 11 μM。先保留冲突，不默认选 10。

**可验收用途：** 在数字提取、状态与协议登记完成后，可评价冻结模型对已知群体状态和两种药物的功能时程、状态响应对比及同一观察时点的药物次序。此用途可以支持或反驳状态条件化预测，不要求先看到有利排序。

**仍未支持：** 没有剂量梯度就不能检验该来源内剂量曲线；10/11 μM 冲突阻止“唯一精确剂量已核实”的声明；连续暴露时程没有自动补齐共同 T* 的撤药时长选择。两种状态和两种药物也不等于广泛新状态/新药泛化样本已经充足。

状态诱导、接种数及背景差异须保留，可评价这套已记录培养状态下的预测效用，不能把差异归因于某一个独立分子机制。当前数值入表及生成器输入接入仍需各自验收。

### 7.2 Sarin：状态条件化的相对 Annexin 响应案例

本会话已亲读 PLOS ONE 2017 的细胞、Apoptosis assay、Fig. 5 及 S8；IJMS 2018 §4.2–4.3 和 GSE108214 元数据。[R2][R3]

A549 与 A549rCDDP2000 是可用的群体状态/背景类别。两者共同的 11 μM 顺铂条件可支持相对诱导响应的状态对照；耐药背景另有 34 μM 条件。不能因为 RNA 是平行 24 h 参考而删除全部类别状态用途。

**尺度限制：** 功能标签为相对各自未处理对照的 fold。可以在该尺度上评价预测或一致性；没有绝对对照比例，就不能恢复绝对 Annexin fraction，跨状态 fold 大小也不等于绝对比例大小。一个药物不支持跨药选择；该表也不是完整两状态×两剂量矩阵。

若不使用 RNA，可以直接进行类别状态的功能案例；若使用 microarray 表达，则另核平台与预处理，不把它当同细胞 t0，也不强行输入单细胞计数模型。

### 7.3 NSH76：三个背景按 IC50 处理的功能挑战，状态与剂量需分开解释

亲读 PMC12538875 的 Sec9、Sec10、Sec23、Sec29、Sec36 及 Fig. 6：研究包含 parental、cisplatin-resistant 和 doxorubicin-resistant A549；NSH76 实验按 IC50 处理，Annexin/PI 方法为 24 h；Fig. 6 的说明为至少三生物重复，误差条为 SEM。[R4]

**可验收用途：** 三种群体背景下已报告处理条件的功能点预测挑战；不要求这三状态都有 RNA。如果用图中均值，应保留“至少三次”而非臆定每点精确 n，并先核具体面板、浓度依据及早期/晚期/总阳性口径。

**不能跳过：** 必须把各背景使用的 IC50 及其依据对应到该条件；不把“1×各自 IC50”改写为同一绝对浓度。若每个状态只对应它自己的一个浓度，则观测到的是状态与剂量的联合变化，不能无额外信息地识别固定剂量下的独立状态增量。

可分别检验“按作者登记条件预测是否准确”和“状态本身是否增加预测价值”，前者可用不代表后者已识别。按 IC50 预筛剂量已使用实验者的敏感性信息，不能把它说成模型从零找到了最优剂量；所有基线应使用同等允许信息。

## 8. 输入不确定性与全结构门槛

对来源内固定药物的剂量/时间研究，来源限定的化合物身份可以足以定义数据。当前 Morgan 指纹消费者需要完整结构，是该消费者的输入约束；不应据此宣布其他合法表示或来源内评估都不可行。对完全未见的药物，仅有一个任意新 ID 通常不能支撑有语义的迁移预测，仍需所选方法实际能利用的结构、描述符或其他经核实输入。

以下为**本课题分析**。若某个条件有多个经来源审查支持的输入解释 θ∈Θ，例如 Nav 的 10/11 μM 或待完成化学审查中的有限立体候选，可事先规定：

1. 固定 Θ 及每个候选的证据，不按哪个预测更接近 Y 来选择解释。
2. 所有分支使用同一冻结模型和同一真实观测 ID，报告预测范围或全部分支的结论。
3. 只有在各允许解释下均成立时，才称结论对该项歧义稳健；不同分支得出不同结论时报告输入不确定。
4. 无证据时不赋予两个结构各 50% 概率；如果采用概率平均，权重和假设须另行论证。
5. 一个 Y 仍只计一个观测，不能因生成两个结构指纹就变成两个独立实验。
6. 现行单结构消费者不支持这种模式时，保留其拒绝，并另建带不确定输入的研究协议。

本文不完成 6k 的原子连接或立体化学裁定。一个化学条件的歧义影响该条件的精确结构评价，不能自动否定整项研究。即使分支结果一致，也只说明对所登记的歧义集合稳健，不证明实际试剂已被最终鉴定。

## 9. 可逐项执行的验收流程

| 检查 | 执行动作 | 通过凭据 | 不通过时的精确结论 |
|---|---|---|---|
| E01 来源与数字 | 亲读原文方法、图注及原图/源表；记录位置、文件与哈希；复算单位/象限 | 一条可复核的观测记录；读图值有误差说明 | 数字/来源未核实，暂不作为已验证标签 |
| E02 状态语义 | 核实状态定义、获得时间、测量或诱导依据 | 类别、背景或观测与当前 Y 独立定义 | 不能用作本次初始状态输入；可另用于测量时状态识别 |
| E03 条件对应 | 核实药物、剂量、实际时间、协议、对照及冲突 | 条件唯一，或有明确允许的有限解释集合 | 精确条件预测暂不成立；可按不确定输入协议限定用途 |
| E04 统计单位 | 区分重复均值、技术重复、面板、共享对照及同孔曲线 | 不重复计数的观测/相关性台账 | 仅描述性使用；不制造独立重复或显著性 |
| E05 任务可计算 | 按 A–D 逐项列出实际单位、比较对象、评价指标 | 能对冻结预测算误差/顺序/选择差距或不确定区间 | 缺哪个对比就保留哪个缺口，不牵连已可计算项目 |
| E06 泛化与防泄漏 | 写出完整的留组/外部冻结方案和数据暴露情况 | 每次评价 Y 没有用于该次模型、校准、方向和候选选择 | 只能作为开发/探索结果，不能称独立确认 |
| E07 方法输入 | 对实际消费者检查状态、药物、时间等输入及冻结特征身份 | 小规模读取/表示链可复现；不依赖缺失字段 | 该实现尚不能使用，区别于数据本身无效 |
| E08 共同终点 | 对时长选择核实 Δt、停止后协议、T* 与 Y(T*) | 至少有可比的真实不同时长候选 | 时间响应可用，共同终点时长选择未覆盖 |
| E09 全目标覆盖 | 建立 A/B/C/D→观测 ID→方案的对应表，并包含完整链的功能评价 | 全部关键目标均有可执行真实检验，且声明剩余范围 | 完整数据可行性尚未通过；已通过组件保留 |

E01–E09 不要求先训练出好结果。对一个已固定检验，可以记录“数据允许评价；方法后续可能无增益”。也不通过设定机械的四来源、四分区或每格固定 n 来代替信息结构与不确定性判断。

每轮交付至少给出：实际可用单位列表、缺失/冲突列表、允许用途、未支撑主张、分组与数据暴露说明、完整目标覆盖表。若公开均值已足以计算该检验，不把拿到原始重复作为无条件的额外前置门槛；若要强显著性或广域泛化结论，必须另说明独立重复、来源数量和统计精度是否支撑。

## 10. 本轮结论与后续使用

Nav-Gal 的原始设计提供了比“同一参考状态配单个终点”更直接的群体状态×药物×时间功能对照，值得完成数值与协议核验；Sarin 和 NSH76 也有各自合法的功能挑战用途。它们不应因缺少同细胞 t0、终点配套高维 RNA、原始逐重复值或现行四分区而被整源否定。

当前不能据此宣称完整主线已通过：曲线数值、输入接口、独立评价仍需落实；尤其是共同 T* 下不同暴露时长的真实结局不能由连续暴露曲线替代。保留完整目标，用上述契约逐项补齐能够支持或反驳它的实际证据。
