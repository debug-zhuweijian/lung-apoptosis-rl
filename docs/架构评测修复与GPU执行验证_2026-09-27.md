## 3. 状态输入和强化学习接口

主链 `BiologicalWorld` 的 root 保存固定观测身份。默认参考由固定种子及数据身份定义，同一 root 下评分种子只改变生成过程，不再改变初始对照抽样。显式输入保存为不可变表达字节，并检查数据身份、完整基因顺序和输入形状。该接口使用当前冻结坐标下的标准化表达。

主链显式输入需覆盖当前群体大小，不能通过静默复制观测细胞补足。默认人口分辨率诊断采用同一固定参考序列的嵌套前缀。时间分支的分辨率诊断则重复同一固定经验起点以改变模拟粒子数，报告已明确这不是新增独立细胞。

两条链都只缓存最近一个 root 的设备表达，防止随着 root 数量增长而无限累积显存。返回副本避免调用方修改污染缓存；主链还对返回元数据作独立复制。时间分支 root ID 包含表达内容、坐标、形状和角色，D 校验登记同时绑定相应 root ID。

主链独立决策评估现已分开报告：

- 原生 Actor 的贪心选择及概率排名；
- 保存的 Q1 动作排序、Q2 诊断及 Q1 贪心选择；
- DLPA 提议器原生选择、搜索过程选定的方案；
- 各自候选池经过统一世界模型重排后的方案；
- 当前单步任务中全部合法候选的模型内比较参照。

原生方案在独立重排之前固定。最终审计只报告，不重新选赢家。所有精确并列项保留，执行时的 action ID 排序是公开的确定性规则，不增加剂量或时长成本。

载入检查覆盖数据、环境、完整奖励/势函数版本、协议和候选版本。Q 仍是相应塑形回报尺度的模型内价值，Actor 输出是动作概率；两者都不能标为真实凋亡率。

主链及时间分支均要求 Actor 和 Critic 实际发生更新后才可将 DA 策略视为已训练。主链 warmup 或 Critic-only 阶段不会占据 best 策略检查点。DLPA 要求发生蒸馏更新。时间分支按保存的实际 Actor 类型转移，支持 conditional 和 joint_control 对照。

STOP 的具体尾协议在主链注册和展开处核查完整状态机；非法尾序列不能绕过普通转移规则。

## 4. 表达评测口径

全方法共同报告 `population_mmd_v`：这是经验群体分布差异，不标为无偏总体估计。未纠偏且不依赖整个参考群体均值时，额外提供共享 control-block 的 U 诊断，排除同一对照位置对应的所有跨成员相关项。

启用群体 K 或使用 `population_mean` 时，相应依赖结构不再被无条件视为独立样本。此时 `shared_control_mmd_u` 留空，经验 V 指标保留。未纠偏基线另存独立字段，避免同列混合不同估计口径。旧的普通拼接 U 不再作为 E 的统一指标。

Ridge 在 E 不重新拟合或选择正则系数；读取冻结 T/V 产物，使用与神经比较相同的 E 对照抽样。此处的对照均值明确为固定 E 样本均值，与原 V 全唯一群体开发报告的口径分别记录。Ridge 均值点没有分布 MMD；其均值平移群体另作为分布基线。

状态独立测试读取保存检查点的 fold，报告逐类支持数/recall、原有状态指标与多类 Brier 分数。标签继续采用 TIDYI 原始分选语义。

## 5. GPU 改造及实测

本轮已接入：

- 状态头真组批，同时保留原先逐单位权重、尾批分母和优化器步数；
- B 训练读取紧凑字段并采用有界本地缓存，避免上传未使用的 raw/observed 全基因数组；
- 冻结编码保留设备张量，复用条件表示；
- 时间 P/B/K/U 模型复用，构造过程隔离全局随机状态；
- 时间投影、统计、坐标转换和误差计算支持 GPU 张量；
- 两条决策链的固定起点采用单 root 设备缓存；
- 时间群体误差始终计算完整细胞和完整基因，使用 FP64。有足够显存时缓存，超预算时按 64 行分块上传计算。

当前误差计算缓存上限为 **1 GiB 和当前空闲显存 1/4 的较小值**。主代理测量发现强制小缓存会增加搬运耗时，因此没有将最省显存的路径强制用于所有输入。这个执行上限不改变样本、基因、带宽或数学目标。

### 完整基因度量探针

设备：RTX 3080，PyTorch 2.13.0+cu130。合成 512 个预测细胞、769 个观测细胞、32,461 个基因，FP64。每条路径暖机 1 次，再测 3 次；不是正式模型训练或生物学效果实验。

| 路径 | 端到端中位耗时 | 峰值额外 allocated 显存 |
| --- | --- | --- |
| 显存充足的缓存路径 | 0.439 s | 349,505,536 bytes |
| 强制 256 MiB 预算的分块路径 | 1.230 s | 50,084,864 bytes |

两条 GPU 路径的结果一致；与 CPU FP64 参考相比，MMD 差为 0，均值误差差为约 `2.71e-20`。[原始测量](../.omo/evidence/implementation-review-20260927/full-gene-gpu-final.json)。

辅助链的 32×32,461 基因字段探针中，B 数据加载 `.to` 次数由 5 降为 3，传输张量字节由 8,439,988 降为 129,972；状态组批的损失、梯度和 Adam 更新已有对照测试。这是相应局部路径证据，不能外推整套训练加速倍数。[辅助链证据](../.omo/evidence/implementation-review-20260927/gpu-auxiliary.md)。

保留 FP32/FP64 原精度、完整基因、原 ODE 和 Monte Carlo 次数；没有启用 AMP、减少评估重复或删除完整 ODE 梯度重放。仍有必要 CPU 读盘、解码、索引与日志处理。实际全尺寸多成员模型的整体吞吐和峰值显存尚未由正式训练测定。
