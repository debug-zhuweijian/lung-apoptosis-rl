依据：[毕业论文研究架构](G:/研究生科研文件/毕业论文/研究架构.md)、[真实数据先导协议 V1](G:/研究生科研文件/毕业论文/真实数据先导实验协议_V1_2026-09-24.md)。此接口对应架构中条件表达分布预测的开发验证，不涉及真实凋亡结局、个体命运或序贯疗效。完整 32,461 基因坐标、五成员模型、生成 ODE 精度和无成本目标保持不变。

## CFM-only 与 CFM+MMD

`src/lung/engine/response.py` 读取 `response.mmd_weight`；未提供时为 1。值为 0 时，在第二批控制/处理细胞抽样之前返回，完全跳过训练 MMD 的生成 ODE、端点损失和重算反传。CFM 本身、V 验证及推理精度检查仍执行。

训练输出包含 `cfm_loss`、原始 `mmd_loss`、`mmd_weight`、`weighted_mmd_loss`、`mmd_computed` 和加权总 `loss`。关闭时两个 MMD 损失为 `None`，`mmd_computed=0`。现有监控器不会把 `None` 写成零；checkpoint 的 `mmd_training=not_computed` 保留其状态。V 的 MMD 继续实算，不能把训练关闭解释为评测关闭。

公共 CFM 的条件顺序、细胞抽样、OT 对抽样及 torch 的噪声与时间流沿同样规则推进；额外 MMD 的细胞、目标平滑噪声及 ODE 初始噪声使用独立 NumPy/torch 流。每个 epoch 由成员与 epoch 种子确定，epoch 末断点保存公共随机状态。内部 checkpoint 仍按原有 `MMD_V + mean_MSE` 选择，没有改成报告中的 U 统计量。

采样规则身份为 `cfm_shared_mmd_separate_v1`，进入响应 checkpoint 身份及 metadata。**旧共享随机流 checkpoint 不允许在新代码下续训**；会明确报 `RESPONSE_RNG_POLICY_CHANGED`，整流水线既有 implementation 身份检查也可能先拒绝。需要保留原实现与原实验环境继续旧运行，或者另建实验 ID。已冻结旧模型的读取函数没有被删除；不得把旧训练结果重新标成此次配对消融。

独立配置可供用户在准备资产已 complete 后手动运行：

```powershell
& 'F:/anaconda/envs/study/python.exe' train.py --config configs/pilot_cfm_only.yaml --run-id pilot-cfm-only-v1
& 'F:/anaconda/envs/study/python.exe' train.py --config configs/pilot_cfm_mmd.yaml --run-id pilot-cfm-mmd-v1
```

这两条训练命令本次没有执行。两份配置均为响应阶段、1000 epoch、五成员、相同主模型与抽样参数，只在 MMD 权重上不同；`auto_prepare=false`，缺预处理资产时直接拒绝。用户原 `configs/train.yaml` 的 `all / both / 1000` 不变。

## V 专用报告

```powershell
& 'F:/anaconda/envs/study/python.exe' scripts/report_response_pilot.py --help
& 'F:/anaconda/envs/study/python.exe' scripts/report_response_pilot.py --output experiments/pilot-p0-v1
& 'F:/anaconda/envs/study/python.exe' scripts/report_response_pilot.py --output experiments/pilot-p0-p2-v1 --shifts experiments/P1-run/v_delta.npz
```

本次仅执行 `--help`。报告入口固定 `EngineData(roles=("V",), allow_test=False)`，不提供切换 E 的参数；传入非 V 配置、含其他读取角色的数据器或非 V 计划会拒绝。底层初始化仍校验冻结资产文件的校验和并读取公共条件/划分元数据，表达读取与抽样仅允许 selection/V；不解码 E 的响应/终点标签，也不拟合预处理。此处不使用固定读取 E 的 `test.py`。

默认 `configs/pilot_v.yaml` 固定八个种子，每条件、每种子最多 512 个不同实测细胞和最多 512 个不同同角色关联对照细胞。对照在关联池合并后按细胞均匀、无放回抽样；这与训练读器的技术样本分层放回抽样分开登记。生成数量等于实际抽中的对照数量，两个群体不强行等长。种子之间允许细胞重现，单组内部不制造独立细胞。

报告使用全部合格 V 条件，拒绝非 24 h 条件，不按响应强弱筛选；缺少对照或均值预测的条件仍保留。计划记录每个条件的化学实体、种子、候选池数、抽中细胞 ID、唯一细胞数与是否放回。`input_and_method_identity.json` 和 `sampling_plan.json` 在读取表达计算指标前保存；输出目录必须位于 `experiments/`，已有目录拒绝覆盖。

产物为：

- `input_and_method_identity.json`：输入、配置、实现指纹、方法与可选均值文件声明。
- `sampling_plan.json`：固定条件和完整抽样身份；各方法共用实测及对照子集。
- `condition_seed_metrics.json`：全部条件、种子、方法、指标和逐项不可算原因。
- `summary.json`：种子 → 条件 → 化学实体等权汇总，P2−P0 的两项主要指标成对差值。
- `status.json`：planned / complete / failed、非完整指标行数与失败原因。

P0/P2 及 P3/P4 成员诊断的主要指标为全基因群体均值 RMSE 和完整三项多尺度 RBF `MMD_u²`。使用冻结 T 内带宽和现有核实现；U 统计量允许负数。这些分布行补充给出全基因差异向量 Pearson 相关、包含零方向的符号一致率、无偏样本方差差的 RMSE、输出有效率。其差异向量统一减去**同一已投影对照群体的均值**，P0 直接复用此投影，因此其预测变化严格为零，相关性为 `null`；不会把 float32 重投影的舍入误差当成方向性效应，也不使用人为小效应阈值。这些分布行的两个主指标比较投影预测与冻结坐标中的原始实测表达。P1 的未投影群体均值，以及 P3/P4 五成员混合的主指标和补充量 NA 口径在下文分别定义。不计算任意逐细胞配对误差，也不重复列出与均值 MSE 相同的差异 MSE。

不足两个唯一预测/实测细胞时，MMD U 与样本方差指标为 JSON `null`；常量差异向量的相关为 `null`；缺预测/缺群体保留原因。物理投影非法时记录有效率，整个该条件种子的误差保持缺失，不删除非法行再算“成功”误差。不会用零填充无法计算的指标。

汇总只使用该指标下所有计划条件和种子均完整的化学实体，并明确报告完整实体数、全部实体数、可算行数和总行数；缺失条件仍在明细与覆盖率中。成对比较使用双方共同完整实体，以固定种子 20260924、10,000 次实体 bootstrap 给出 95% 区间；少于两个完整实体时区间为 `null`。区间仅描述开发域波动，不能补偿多轮 V 选参偏差，也不将细胞或成员当生物重复。

## 第二轮：P3/P4 五成员报告接入

新增 `src/lung/engine/pilot_response.py`。同一次报告可通过 `--p3-checkpoints` 和 `--p4-checkpoints` 各显式传入五个路径；路径按当前项目的 `checkpoints/<run_id>/response/member_1..5/<checkpoint>.pt` 注册。不是靠文件名推断 P3/P4：读取 checkpoint 内部 member 0–4、响应配置、模型形状、数据身份、MMD 权重、`rng_policy`、T 拟合/V 选择角色和已训练 epoch，并复算响应身份；同时核对同一 run 的配置哈希、数据登记和基因图。五个文件必须属于同一 run，成员不得缺失、重复或混入另一目标。正式入口拒绝合成资产；单元测试另用明确标记的小型合成夹具。

P3 必须为 `mmd_weight=1` 与已计算 MMD；P4 必须为 0 与未计算 MMD。两者同时比较时，完整响应配置除权重外必须一致。冻结数据身份绑定当前基因轴与预处理资产，报告另外记录基因 ID 顺序哈希、checkpoint 哈希、epoch、成员初始种子与 run。加载前后及报告后检查模型文件哈希，不能一边更新同一路径权重一边把结果当冻结比较。

每成员使用其配置中的完整 Heun 推理步数，真实模型至少为 128 步。有匹配的已通过 V ODE 审计时，只能取两者较大值；P3/P4 共同使用双方所需的最大步数。没有审计时记录 `not_attached_checkpoint_precision_only`，不声称已证明数值收敛。使用原 `inference_microbatch` 分批生成；GPU 同时只放一个成员，五个模型保留在 CPU，每条件/种子仅保存当前五个生成群体，不跨全部 V 条件累积表达矩阵。

示例参数形式（五条路径需换成已经训练的实际文件；本轮未执行此命令）：

```powershell
& 'F:/anaconda/envs/study/python.exe' scripts/report_response_pilot.py --output experiments/pilot-models-v1 --p3-checkpoints <P3成员1.pt> <P3成员2.pt> <P3成员3.pt> <P3成员4.pt> <P3成员5.pt> --p4-checkpoints <P4成员1.pt> <P4成员2.pt> <P4成员3.pt> <P4成员4.pt> <P4成员5.pt>
```

P3/P4 的模型成员共用计划中同一组对照与实测细胞，并共用按条件/报告种子确定的独立高斯噪声。该噪声流与细胞抽样流分开，且不依赖方法名或成员编号，所以不同方法、成员接收同一 `(control_i, noise_i)` 块。种子与策略先写进抽样计划，再运行模型。所有输出先按同一物理投影处理，非法成员/行保留失败，不能删除后只报其余成员。

五成员主方法的均值为五个预测群体均值的等权平均；分布保留所有成员的样本及交叉成员核项，绝不把五个表达向量先逐细胞平均再作为预测分布。令 `K=5`、每成员 `n` 个共享对照块、`m` 个实测细胞：

\[
\widehat D_{\mathrm{block}}=
\frac{\sum_{k,l=1}^{K}\sum_{i\ne j}k(x_{ki},x_{lj})}{K^2 n(n-1)}
+\frac{\sum_{r\ne s}k(y_r,y_s)}{m(m-1)}
-\frac{2\sum_{k,i,r}k(x_{ki},y_r)}{Knm}.
\]

这是共享对照设计下的 **block U estimator**：跨成员也排除同一个块索引 `i=j`，保留其他全部交叉成员项。核与全基因距离沿用现有实现；128×128 的核子矩阵逐块累加，不创建 `(5n)×(5n)×G` 张量，不减少 n 或 G。当 `n<2` 或 `m<2` 时该指标为 `null`；负值保持原值。五成员逐块相同时，它退化为 n 个预测块的普通 U 统计，而不是把重复输出当成 5n 个独立样本。

只有在块 IID、实测细胞 IID 且二者独立、模型与核事先固定时，才能将该统计的期望解释为等权混合分布与观测分布的总体 MMD²。实际固定 V 池无放回采样对应有限总体的 off-diagonal 泛函；模型也用 V 选过 checkpoint，因此本报告不作无条件无偏或最终测试保证。记录的是 `n_blocks=n` 与 `correlated_generated_outputs=5n`，不把任何一个直接称为有效样本量，不把模型成员当生物重复。

`condition_seed_metrics.json` 每个 P3/P4 方法、条件、种子只放一条混合主指标行。新增 `response_member_metrics.json` 保存所有成员的标准 U 指标、种子、epoch 和模型哈希，供定位问题；成员行不进入化学实体 bootstrap。混合行只定义两个主要指标和输出有效率，其他补充量标 `not_applicable`，可从成员明细查看。汇总额外给出 P3−P4 的配对差值，并沿用化学实体重采样。命令行默认显示条件、种子、成员、微批细胞范围和 ODE 当前步；刷新按既有进度机制限频，可用 `--no-progress` 关闭。

### P1 均值点与控制信息范围

若 `--shifts` 指向的新 NPZ 同时包含 `mean_prediction` 与 `point_valid`，报告通过 `pilot_ridge.load_mean_predictions()` 接入 P1。P1 是完整 V 对照池均值加预测变化得到的标准化群体均值，保持原训练坐标，只检查有限值，不施加单细胞物理投影。群体的平均 log 表达不必位于单细胞归一化流形上；把它当单细胞重新投影会改变均值估计目标。这里只计算群体均值 RMSE 和点的有效率，不把它扩成单细胞分布。MMD、方差及本入口未定义的差异方向补充量标为 `not_applicable`；缺失/非法均值点才是失败。覆盖汇总分开登记可算、不适用与缺失/失败，不把 P1 的全部分布指标 NA 当运行异常。旧的“投影后均值点”资产由新的 P1 语义字段校验明确拒绝；P0/P2/P3/P4 仍对每个细胞输出实施物理投影。

逐行记录 `control_summary_scope`：P1 为 `full_unique_V_control_pool_mean`；P0/P3/P4 为 `sampled_V_controls`；P2 的平移群体使用抽样对照，外部 delta 的控制汇总范围另记 `delta_control_summary_scope`。本轮 Ridge 预测的 delta 使用完整 V 对照池均值。它们利用同一可用 V 对照信息，但估计器及具体输入摘要不同，不能声称五者严格使用相同抽样输入；主报告如实记录该区别。

同名输出有效率也必须按定义读取：P1 行标记 `output_validity_definition=finite_mean_vector_only_not_cell_physical_validity`，其余生成群体为 `per_cell_physical_projection`；汇总保留定义。P1 的有限值检查不保证该向量一定能由某个可实现的细胞群体产生，不能把它与逐细胞物理有效率直接当同一种保证比较。

## 均值平移文件格式与当前边界

P0 输入为抽中的同角色对照群体；P2 为同一群体加上 **T 拟合的 P1 岭回归预测均值差**，两者均经过现有全基因物理投影。

外部 NPZ 必须包含无 pickle 的数组 `condition_ids`、`gene_ids`、`delta` 和字符串标量 `metadata_json`。`delta` 为条件数 × 32,461 的有限值矩阵，在冻结训练坐标中表示预测均值差。基因顺序必须逐项相等，条件 ID 唯一且全部属于 V；可以缺 V 条件，但报告将保留缺口。

`metadata_json` 必须声明下列字段：

| 字段 | 要求 |
|---|---|
| `schema_version` / `model_family` | `1` / `full_gene_ridge` |
| `fit_role` / `selection_role` / `evaluation_role` | `T` / `V` / `V` |
| `prediction_inputs` | 精确为 `["V_controls", "condition_metadata"]`；不得含 V 药后表达 |
| `data_identity` | 与当前冻结 EngineData 身份相等 |
| `fit_condition_ids` | 非空且全部为冻结 T 内 treated 条件 |
| `fit_code_sha256` / `fit_artifact_sha256` | 原拟合代码与模型资产的完整 SHA256 字符串 |

这些检查核对角色声明、划分、数组和数据身份，**不能独立证明外部文件的实际拟合过程合规**。报告明确记录 `identity_and_declared_provenance_only_not_training_audit`；实际 P1 实现、训练内缩放、正则选择与输入数据流仍须代码审查和独立验证。

第二轮已经补上 P1 Ridge 拟合与 `v_delta.npz` 生成接口、P1 均值点/P2 分布报告，以及 P3/P4 五成员报告接入；各接口通过小型合成数据和临时 checkpoint 检查。**真实预处理就绪核验、真实 Ridge/响应训练及真实 V 效果比较仍待手动执行**，不能将工程测试写成先导性能结论。训练内部 V 选 checkpoint 规则继续独立保留，不用它冒充本报告的全部分布与混合指标。
