# SCCP：不能把聚类推定命运当作真实未来凋亡标签

2026-10-10定向资格审查。[论文](https://doi.org/10.1021/acs.analchem.2c00413)，[PMC9260713](https://pmc.ncbi.nlm.nih.gov/articles/PMC9260713/)。SciSpace返回2021预印本与2022正式版，按版本关系合并为一项线索。主代理已读取Europe PMC官方XML的方法、结果和Fig2/3上下文，源文件及SHA256见`source.json`。

主文[第41、45行](PMC9260713_text.md:41)说明，在各药后时间点收集贴壁细胞、做破坏性的单细胞蛋白组分析，另在48h收集贴壁/脱落群体的bulk蛋白组。不是同一个细胞被测蛋白后继续随访。

[第77行](PMC9260713_text.md:77)明确将两个主要蛋白聚类假设为将死/将存活群体，再用它们相对48h贴壁/脱落bulk蛋白组的位置解释命运。这里的G1/G2是分析簇标签，不能自动解释为细胞周期G1/G2。

因此，本研究提供A549多药和药后时间点的**蛋白组异质性**资料，不能把该分析生成的命运簇当作独立实测Annexin、未来死亡追踪或处理前RNA。数据入口PXD025481仅从原文定位，本轮未下载或读取蛋白矩阵；未把蛋白组直接送入RNA消费者。

本轮不继续提取命运标签，不计为新的A549初态—实测凋亡桥。该判断限于当前任务的监督资格，不否定该论文的蛋白组研究价值。
